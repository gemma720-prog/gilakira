# 神算 Property Calculator MY

神算是给马来西亚房产经纪使用的网页计算器，可计算投资回报（ROI）、产业盈利税（RPGT）、印花税、律师费与贷款相关费用，并生成双语报告。

Shen Suan is a web calculator for Malaysian property agents. It covers investor ROI, RPGT, stamp duty, legal fees and loan-related costs, and can generate a bilingual report.

This repository hosts the static site for GitHub Pages.

Live site: https://gemma720-prog.github.io/shensuan/
