# 神算 GilaKira.com

神算是给马来西亚产业经纪和高端投资者用的网上计算器，涵盖投资回报（ROI）、产业增值税（RPGT）、印花税、律师费与贷款相关费用，并能生成双语报告。

Shen Suan (GilaKira.com) is a web calculator for Malaysian property agents and sophisticated investors. It covers investor ROI, RPGT, stamp duty, legal fees and loan-related costs, and can generate a bilingual report.

This repository hosts the static site for GitHub Pages.

Live site: https://gemma720-prog.github.io/gilakira/
